# RuleGrid

A hairline grid: 1px gaps over a `c-border` field, three columns from 768px, one below. It holds RuleCard or PricingTier children. Hand-written from the `gap-px border bg-border md:grid-cols-3` pattern in `problems.tsx`, `pricing.tsx` and `future-vision.tsx`.

Use it for three parallel ideas. The source repeats this exact grid in three sections in a row; vary at least one of them.
