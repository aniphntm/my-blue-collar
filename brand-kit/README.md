# MyBlue brand kit

## Current logos

The current identity uses custom rounded lowercase lettering and a blue gradient. These are vector paths, not typeset text; no font installation is needed.

## Folder structure

- `assets/logos/`: current rounded logo family, editable SVG and transparent PNG exports.
- `assets/`: preserved existing app icons, older uppercase/text-based SVG logos, and supplied PNG filenames. The older `mb-logo.svg` and `myblue-logo.svg` use Arial/Helvetica and are not the current rounded artwork.
- `fonts/`: typography notes and source information.
- `guidelines/`: colors and usage guidance.

The former repository-root `assets/` directory is now `brand-kit/assets/`. App-specific runtime icons in `apps/mobile/assets/` remain at their configured paths.

See [typography](fonts/README.md) and [usage](guidelines/usage.md).
