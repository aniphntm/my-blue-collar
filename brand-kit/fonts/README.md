# Typography

## Logo lettering

The lowercase `mb` and `myblue` logos are custom SVG path artwork created for this kit. There is no original TTF, OTF, or WOFF font. Use the SVG files for precise reproduction; this kit does not contain a complete alphabet or a custom font binary.

## Website text

The working website references Google Sans, weights 400–700, normal and italic, with optical sizing. This is supporting typography, not the logo lettering.

Official source: https://github.com/googlefonts/googlesans

No Google Sans binary is bundled: the download was not approved during packaging. Obtain fonts and their accompanying license from the official source before distributing font files. Existing fallback stack: Arial, Helvetica, sans-serif.
